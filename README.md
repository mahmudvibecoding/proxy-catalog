# Proxy catalog cloud feasibility test

This private repository is currently a minimal fixture for testing Codex Cloud.
The production proxy catalog has not been uploaded.

## Scope of this test

Verify that a subscription-backed cloud task can start, use Python's standard
library, fetch a small public HTTPS response, and publish a tiny private GitHub
release asset. Check whether that same environment supports a scheduled run.

Do not start proxy testing, bulk source collection, or database migration.
Do not configure paid APIs, additional credits, or shared-server credentials.
No package installation or background service is required for this fixture.
